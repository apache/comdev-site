## Post Event Report

The event was attended by approximately 70 students. It was conducted online on Google Meet.  
Interested students were asked to register for the event beforehand via Google forms and event links were sent via email.

It was a 1-hour session followed by a 30 minutes Q & A.

We also talked about the opportunities and initiatives that can help students gain experience and knowledge by contributing to Open source projects.

## Agenda

ALC Indore is planning to organize a second webinar on 'Open Source and ASF Awareness' on 21st November 2020 for the undergraduates at [LNCT, Indore](https://www.lnctindore.com/).

In these sessions, our main emphasis is imparting knowledge about Open Source and the Apache Software Foundation to the students.  
So as to benefit them in building their skillset by encouraging them to get involved in Open Source projects under Apache.

### Session on the Open-Source and The Apache Software Foundation

Aditya Sharma & Sourabh Jain will be the speaker for the session and talk about the following topics -

Open Source & The Apache Way

\# Open Source  
\- What is Open-Source  
\- History of Open-Source  
\- Open-Source license

\# OpenSource Opportunities  
\- Internships  
\- Jobs

\# The Apache Way  
\- About the Apache Software Foundation and its history  
\- About the Apache Way  
\- ICLA and how it should be signed to contribute to ASF  
\- Apache Incubator  
\- The Foundation structure  
\- The projects under the Apache umbrella  
\- The Mailing list and it's uses  
\- How to pick a project based domain/programming language interest
