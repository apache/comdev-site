## Post Event Report

This was altogether a different experience for us, we tried a new variation of events.  
Herein we selected a group of dedicated enthusiasts and worked with them for two weeks.

During the first, we talked about different aspects of The Apache Way in detail.

In the second week, we explored the Apache OFBiz project, helped them understand the framework along with developing some basic skills that would eventually help them in their open-source journey

**At the end of the workshop, all our participants were able to understand how an open-source community works and make their first contributions to various Apache projects.**

## Agenda

The workshop will be of 2 weeks duration and cover the following topics:

Week 1:

1.  Open-source software
    1.  History
    2.  Why you should know about Open Source?
    3.  Why one should contribute to Open Source?
    4.  Perceptions Blocking contribution
    5.  How can one contribute?
    6.  Where to start?
2.  Open Source License ( Copyleft/ Copyright )
3.  CLA
4.  Open Source opportunities
    1.  Internships
    2.  Jobs
5.  Open Source Foundations & their role
6.  Apache Software Foundation
7.  ASF - Brief History
8.  Apache Project Ecosystem
    1.  Resources - Mailing list, GitHub Repos, etc
    2.  Community - PMC, Committer, Contributors, and Users
9.  Apache Way
10. Apache Incubator
11. Where to start?

Week 2:

1.  Apache OFBiz
    1.  Briefly Introduction
    2.  Setup
    3.  Documentation (Readme and confluence )
    4.  Build tools (Gradle)
    5.  Understanding the control flow
    6.  controller, screens, services & events

Following will be the speakers:  
1\. Aditya Sharma  
2\. Praveen Sharma  
3\. Priya Sharma  
4\. Sourabh Jain

We will take some open registrations as well as registrations from students specific to colleges for this event.
