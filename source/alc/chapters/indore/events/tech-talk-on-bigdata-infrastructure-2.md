### Post Event Report

Last Friday we organized a tech talk with Joshua Poddoku (Lead Evangelist Apache DevLake) and Jia Fan ( Apache SeaTunnel PPMC) to discuss the popular use cases and where these open-source projects fit into the big data ecosystem.  
  
We hope everyone enjoyed and found value in the delivered content.  
  
This was the second and final session of our "Tech Talk on BigData Infrastructure" series.  
The series was aimed to share technical insights on various Apache projects in the big data area, and get contributors and users connected.  
  
Some key takeaways from the session were:  
? What is SeaTunnel and how to use it  
? Advantages over traditional data synchronization  
? A quick guide by referring to use cases to help you know and experience SeaTunnel, and help new users quickly implement SeaTunnel in the production environment.  
? Discuss problems faced by developer teams and how we can improve productivity with DevLake.  
? Explore different use cases for Open Source maintainers with visualization of Community and DORA metric Dashboard using Grafana.  
  
We are committed to bringing many such events in the future.
