### Post Event Report

We hosted the event via zoom and the registrations were done via Eventbrite <https://www.eventbrite.com/myevent?eid=456942807237> and Meetup.com <https://www.meetup.com/india-big-data-group/events/289521615/>  
We got around 15 attendees in the session.

The first half of the session delivered By William was about the different tools used in the BigData infrastructure and what purpose they serve. He later threw light on several case studies where Apache Dolphine Schedular is used.

The second half of the session was delivered by Jay wherein he explained in detail the utility and technicalities related to Apache DolphinSchedular with a great set of examples and an engaging presentation.

Though the audience count was less than expected. We will retrospect and improve the plan for more engagement.

Our aim to conduct this event was to spread awareness about the project and get users and developers connected, which did have some fruit looking at the response from the audience and the level of their questions.  
So overall it was a great experience and we build some friends in China on the course and a few followers on our ALC page. 😛

### Agenda

We are planning a series of inter-community technical virtual sessions in collaboration with the Apache DolphinSchedular team.

Our goal is to share technical insights and best practices of the Apache DolphinScheduler in the big data area and get engineers between China and India connected. If you are a developer, system engineer, or any other IT professional who is excited about infrastructure technologies, the BigData Infrastructure Webinar will definitely bring you something you want.

-----

### 19th November 2022

**Duration:** \~2 hour  
**Audience:** Students or Professionals (BigData enthusiasts)  
**Timing:** 2 PM IST onwards  
**Type:** Virtual

Speaker: William GUO, Apache Foundation Member

New Generation of Big Data Workflow Orchestration Platform: Apache DolphinScheduler

Summary:

  - Help the audience to quickly understand the latest features of the new generation of Modern Data Stack: "de-specialization", "de-centralization", "extremely fast experience", "use as needed",
  - sharing and explaining what is MDS( Modern Data Stack)
  - how to use the Apache open-source project to implement MDS.

Speaker: Jay Chung, Apache DolphinScheduler PMC

DolphinScheduler, what is it, and how it works

Summary:

  - What is DolphinScheduler?
  - How to create your first workflow?
  - Why is it useful during data pipeline jobs?
  - How does it schedule workflow?
  - What ecosystem is have?
