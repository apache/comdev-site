## Post Event Report

The event was attended by approximately 20 people. It was conducted online on Google Meet.  
Interested parties were asked to register for the event beforehand and event links were sent via email.

It was a 1-hour session and we also shared videos clips from the "Why Apache?" trailer and "Apache Innovation" official videos.

We also talked about the opportunities and initiatives that can help students gain experience and knowledge by contributing to Open source projects.

Informed them about the upcoming ApacheCon 2020 and what all they can expect from it.

## Agenda

ALC Indore is planning to organize a second webinar on 'Open Source and ASF Awareness' on 12th Sep 2020 for the undergraduates at [MIT Ujjain](http://www.mitujjain.ac.in/).

In these sessions, our main emphasis is imparting knowledge about Open Source and the Apache Software Foundation to the students.  
So as to benefit them in building their skillset by encouraging them to get involved in Open Source projects under Apache.

### Session on the Open-Source and The Apache Software Foundation

Aditya Sharma & Priya Sharma will be the speaker for the session and talk about the following topics -

Open Source & The Apache Way

Open-source software

  - What is Open source software?
  - History
  - Comparison with closed source
  - Why you should know Open Source?
  - Why you should contribute to Open Source?
  - Open-Source Opportunities

Apache Software Foundation

  - History
  - The Apache Way
  - Principles
  - Projects
  - Apache Project Ecosystem
  - How to contribute
  - Ways to contribute
  - Where to start
