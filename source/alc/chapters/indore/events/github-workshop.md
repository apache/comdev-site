### Agenda

Acropolis Institute of Technology and Research, Indore has invited ALC Indore team to deliver a GitHub workshop for their students. This workshop will help empower the students to be one step forward into their open source journey as Git and GitHub are important pillars of any open source project. And getting a hands-on exposure early in their careers will be helpful for their future. We aspire to bring in more contributions to the Apache projects by developing interest and awareness in the college students.

This will be an in-person hands-on workshop and session scheduled on 5th September 2023, Tuesday.

We will be covering the following topics:

Introduction to version control

Git

  - Repository
  - Configuration
  - Stages of a file
  - Reset and revert
  - Diffing
  - Branching
  - Merge conflicts
  - Stashing
  - Remote

GitHub

  - Forking and Pull Request

(Speaker: Priya Sharma & Aditya Sharma)
