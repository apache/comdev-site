## Post Event Report

The ALC Indore successfully organized a webinar on "Open Source and ASF Awareness" Session at Indore on 11th July 2020 for [Medicaps University](http://www.medicaps.ac.in/), Indore.

The session was attended by approximately 10 students wherein Aditya guided them about Open Source and The Apache Way.  
They were also given details about how they can leverage it as an opportunity to enhance their skills and how great it feels to be working in an Open Source community.  
  
We conducted the webinar via Google Meet and it was a 1-hour session.

## Agenda

ALC Indore is planning to organize a second webinar on 'Open Source and ASF Awareness' on 11th July 2020 for the undergraduates at [Medicaps University](http://www.medicaps.ac.in/), Indore.

In these sessions, our main emphasis is imparting knowledge about Open Source and the Apache Software Foundation to the students.  
So as to benefit them in building their skillset by encouraging them to get involved in Open Source projects under Apache.

### Session on the Open-Source and The Apache Software Foundation

Aditya Sharma will be the speaker for the session and talk about the following topics -

Open Source & The Apache Way

  - What is Open-Source
  - History of Open-Source
  - Open-Source Vs Closed source
  - Open-Source license
  - About the Apache Software Foundation and its history
  - About the Apache Way
  - ICLA and how it should be signed to contribute in ASF
  - Apache Incubator
  - The Foundation structure
  - The projects under the Apache umbrella
  - The Mailing list and it's usage
  - How to pick a project based domain/programming language interest
