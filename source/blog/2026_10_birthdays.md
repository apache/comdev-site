The following Apache projects are celebrating their birthdays in October.

## Apache Ozone (6 years)

**Established:** 2020-10

**Description:** The mission of Apache Ozone is the creation and maintenance of software related to a distributed object store for Hadoop-based and Cloud-native environments

**Project Homepage:** https://ozone.apache.org

---

## Apache SINGA (7 years)

**Established:** 2019-10

**Description:** The mission of Apache SINGA is the creation and maintenance of software related to a distributed deep learning platform

**Project Homepage:** https://singa.apache.org/

---

## Apache ServiceComb (8 years)

**Established:** 2018-10

**Description:** The mission of Apache ServiceComb is the creation and maintenance of software related to a microservice framework that provides a set of tools and components to make development and deployment of cloud applications easier.

**Project Homepage:** https://servicecomb.apache.org/

## Apache Juneau (9 years)

**Established:** 2017-10

**Description:** The mission of Apache Juneau is the creation and maintenance of software related to a toolkit for marshalling POJOs to a wide variety of content types using a common framework, and for creating sophisticated self-documenting REST interfaces and microservices using VERY little code

**Project Homepage:** https://juneau.apache.org/

## Apache XML Graphics (22 years)

**Established:** 2004-10

**Description:** Apache XML Graphics exists to promote the use of XML. We view XML as a compelling paradigm that structures data as information, thereby facilitating the exchange, transformation, and presentation of knowledge. The ability to transform raw data into usable information has great potential to improve the functionality and use of information systems. We intend to build freely available products for the conversion of XML to graphical output and closely related technologies in order to engender such improvements.

**Project Homepage:** https://xmlgraphics.apache.org/

---

## Apache Xalan (22 years)

**Established:** 2004-10

**Description:** Apache Xalan exists to promote the use of XSLT. The ability to transform XML documents into usable information has great potential to improve the functionality and use of information systems. We intend to build freely available XSLT processing components in order to engender such improvements.

**Project Homepage:** https://xalan.apache.org/
