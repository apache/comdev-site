Post Event Report ¶

We hosted the event on zoom and gathered registrations from Eventbrite https://www.eventbrite.com/myevent?eid=461630026837.
The event was also announced on the official mailing list of the respective project.

We were overwhelmed by the number of attendees i.e. 48 even on such short notice of the announcement.

Navendu was on point with his presentation and kept the audience engaged till the end of the session. He talked about various topics starting from basic to advance.
The audience seemed to grasp it well and Navendu answered their questions towards the end of the session.

Overall the event was a big hit and we are positive of the audience take away a lot of insights about Apache APISIX and API gateways at large.

Agenda ¶

We are planning a series of inter-community virtual technical sessions on Apache APISIX.

Apache APISIX provides an open-source API Gateway to help you manage microservices, delivering the ultimate performance, security, and scalable platform for all your APIs and microservices.

Our primary aim is to spread awareness about the project and provide necessary information/resources for those interested in the project and API gateways at large.

https://apisix.apache.org/

Date: 11th November 2022, Friday ¶

Duration: ~1 hour
Mode: Virtual

In this session we are planning to cover the following topics :

  • What API gateways are
  • What problems do they solve
  • What Apache APISIX is
  • How Apache APISIX provides security, traffic control, scalability, and monitoring
  • How you can run APISIX How you can contribute to APISIX

Speaker: Navendu Pottekkat Maintainer of Apache APISIX,
Former Maintainer of Meshery and Service Mesh Performance at Cloud Native Computing Foundation,
Mentor at GSoC and LFX Mentorship
